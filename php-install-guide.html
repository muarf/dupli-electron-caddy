⚠️

PHP n'est pas installé sur votre système

Duplicator nécessite PHP pour fonctionner. Veuillez l'installer selon votre distribution Linux.

macOS (Apple Silicon & Intel)

Si ce n'est pas déjà fait, installez Homebrew, puis les paquets requis :

# 1. Installer Homebrew (copiez/collez dans le Terminal) /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" # 2. Installer PHP, Ghostscript et ImageMagick brew install php ghostscript imagemagick

Debian / Ubuntu / Linux Mint

sudo apt update sudo apt install php php-cli php-gd php-sqlite3 php-mbstring php-xml

Fedora / RHEL / CentOS

sudo dnf install php php-cli php-gd php-pdo php-mbstring php-xml

Pour CentOS/RHEL plus anciens, utilisez yum au lieu de dnf

Arch Linux / Manjaro

sudo pacman -S php php-gd php-sqlite

Extensions PHP requises

Duplicator nécessite les extensions PHP suivantes :

✓ php-gd
✓ php-sqlite3
✓ php-mbstring
✓ php-xml
✓ php-cli
📝 Note importante :

Après l'installation de PHP, vous devrez peut-être redémarrer votre terminal ou votre session pour que les modifications prennent effet.

Pour vérifier que PHP est correctement installé, ouvrez un terminal et tapez :

php --version
